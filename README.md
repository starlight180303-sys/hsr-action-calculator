# 崩壊：スターレイル 行動順・行動値計算機

GitHub Pagesでそのまま公開できる、静的HTML/CSS/JavaScript版です。

## ファイル構成

```text
.
├── index.html
├── README.md
└── .nojekyll
```

## 実装済み機能

- 4人編成のキャラクター選択
- キャラクター検索
- 速度入力
- 開幕行動順アップ
- DDD S1〜S5、鷹4、ウェンワーク、ブローニャ、サンデー、花火プリセット
- 忘却の庭 / 混沌、虚構叙事、末日の幻影、異相の仲裁の切り替え
- 行動回数サマリー
- 行動値タイムライン
- 速度目標表

## 注意

このツールはファンメイドです。HoYoverse公式とは関係ありません。
敵行動、召喚物、追加ターン、速度変動の持続ターン消費などは未実装です。
